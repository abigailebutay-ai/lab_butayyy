lab_butayyy — Laravel Mini Social App
A simple social-style Laravel application where users can create posts, like tweets, edit profiles, and interact with the platform. This project is designed for learning Laravel fundamentals while applying modern UI principles and MVC architecture.

🚀 Project Description & Purpose
lab_butayyy is a Laravel-based project created to practice essential development concepts such as:

Authentication (login, registration)

CRUD operations (Create, Read, Update, Delete)

Eloquent relationships

Blade templates and UI layouting

Controller-service structure

Routing and form validation

Git/GitHub workflow

The purpose is to give hands-on experience in building a functional web application while learning clean code and repository management.

⭐ Features Implemented
✅ User Features
User Registration & Login

Update Profile (name, email, bio, profile picture)

View User Profiles

📝 Tweet/Post System
Create a Tweet

Edit a Tweet

Delete a Tweet

View Tweets feed

❤️ Likes System
Like & Unlike Tweets

Like counter

🎨 UI & Styling
Modern aesthetic UI

Styled using TailwindCSS

Clean and readable layout

🛠️ Installation Instructions
1. Clone the repository
git clone https://github.com/abigailebutay-ai/lab_butayyy.git
cd lab_butayyy
2. Install dependencies
composer install
npm install
npm run dev
3. Copy environment file
cp .env.example .env
4. Generate application key
php artisan key:generate
🗄️ Database Setup
1. Create a database in your local environment
Example name: lab_butayyy

2. Update .env database section
DB_DATABASE=lab_butayyy
DB_USERNAME=root
DB_PASSWORD=
3. Run migrations
php artisan migrate
